# Python-Security-Lab

A beginner-friendly Python project demonstrating basic
request rate limiting and event logging.

## Features

- Limits requests within a time window
- Allows or blocks simulated requests
- Records events in a local log file
- Uses only local test data
- Does not send SMS or WhatsApp messages

## Requirements

- Python 3

## Run

```bash
python lab.py
## Purpose

This project teaches defensive programming, request rate
limiting, and basic security logging.

All tests are local simulations.
